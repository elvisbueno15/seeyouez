Privacy Policy — SeeyouEz Uploader

Uses YouTube API Services

Last updated: October 17, 2026.

SeeyouEz Uploader ("the tool") is a private desktop tool that runs only on the computer of its owner, Elvis Bueno. Its only purpose is to upload and schedule the owner's own videos on the owner's own YouTube channels.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Information the tool accesses, uses and stores

  • OAuth access token / refresh token for the connected YouTube channel, with the scopes youtube.upload and youtube.readonly. Stored only on the owner's computer.
  • Channel ID and channel title (channels.list, mine=true), used only to confirm the correct channel is connected. Stored only on the owner's computer.
  • Video IDs returned after each upload, saved locally so the same video is not uploaded twice.
  • The videos, titles, descriptions, tags and thumbnails the owner created himself.

How the information is used and shared

The information is used only to upload and schedule the owner's videos. It is not sold, shared or disclosed to any third party, except that videos and their metadata are sent to YouTube/Google to publish them. The tool does not collect data from viewers or other users, does not use cookies, and does not place any tracking or analytics on any device.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page (https://myaccount.google.com/permissions). When access is revoked, or on request to the contact below, the stored tokens and channel data are deleted from the owner's computer within 7 days. Tokens that stop working are deleted and are never kept longer than 30 days without being refreshed.
